# quest

quest keeps one directory for each task you work on.
A task is a small working session with a clear goal.
For example: "install nix on my machine", "run pi in a secure sandbox", or "fix bug foo in repo bar".

The directory holds everything the task needs and everything it produces.
It is a place to work, and it is a record to keep.
When the task is finished, quest removes the disposable parts and keeps the rest.
