# quest

quest keeps one directory for each quest you work on.
A quest is a small working session with a clear goal.
For example: "install nix on my machine", "run pi in a secure sandbox", or "fix bug foo in repo bar".

The directory holds everything the quest needs and everything it produces.
It is a place to work, and it can be used to keep a record of your past work topics.
When the quest is finished, quest removes the disposable parts and keeps the rest.

quest is in early development and it is not usable yet.
